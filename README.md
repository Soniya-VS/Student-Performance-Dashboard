# 📊 Student Performance Dashboard

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Project Overview
This project presents an interactive Power BI dashboard to analyze student performance based on attendance, study hours, subject scores, gender, class, city, internet access, and parent education.

## Dataset
- 9,851 student records

## Files
- Raw Dataset (.csv)
- Preprocessed Excel File
- Power BI Dashboard (.pbix)
- Dashboard Screenshots
